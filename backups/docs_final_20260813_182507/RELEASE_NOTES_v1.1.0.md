# ChronoOS 1.1.0

## Overview

ChronoOS 1.1.0 is the next development release of the ChronoOS
dedicated-system platform.

ChronoOS targets dedicated infrastructure, security appliances,
industrial monitoring systems, communication equipment and Core Box
deployments.

## Included

- ChronoOS init runtime
- ChronoD service supervision
- ChronoCTL management interface
- ARM64 boot artifacts
- Initramfs infrastructure
- Structured logging
- Recovery infrastructure
- Security components
- Network components
- Industrial/Modbus components
- 5G integration components
- Hardware policy components
- Build system improvements
- Documentation improvements

## Verification status

Components are identified separately as implemented, experimental,
or planned. Features are not considered production-ready solely
because source code or binaries exist.

## Scope

ChronoOS is not intended to be a general-purpose desktop operating
system. Its primary target is dedicated infrastructure and appliance
deployments.

## Security

Private keys, credentials and deployment secrets must never be stored
in the public repository.

## Development

The current release is intended for engineering evaluation and
controlled deployments. Production certification or compliance claims
must not be inferred from this release.
