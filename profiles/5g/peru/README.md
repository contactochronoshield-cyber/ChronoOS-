# ChronoOS 5G — Perú

## Perfil regulatorio

**País:** Perú  
**Código:** PE  
**Autoridad:** Ministerio de Transportes y Comunicaciones (MTC)  
**Tecnología:** 5G NR

### Espectro principal

- 3300–3800 MHz
- Enfoque principal: banda de 3.5 GHz

El MTC estableció en 2025 un mecanismo de asignación y
acondicionamiento de la banda 3.5 GHz para servicios públicos de
telecomunicaciones mediante 5G o superior.

El perfil ChronoOS sirve para planificación e ingeniería. No constituye
por sí mismo una concesión ni autorización de espectro.

### Autoridad

https://www.gob.pe/mtc

### ChronoOS

Preparado para infraestructura 5G, Core Box, redes privadas y
despliegues controlados.
