# ChronoOS 5G — El Salvador

## Perfil regulatorio

**País:** El Salvador  
**Código:** SV  
**Autoridad:** SIGET  
**Tecnología:** 5G NR

### Espectro

El uso de espectro radioeléctrico regulado está sujeto al régimen de
concesiones y autorizaciones de SIGET.

ChronoOS no fija una banda 5G arbitraria en este perfil. Las frecuencias
deben validarse contra el Cuadro Nacional de Atribución de Frecuencias,
las condiciones vigentes y la autorización correspondiente.

### Autoridad

https://www.siget.gob.sv/

### Uso

Este perfil permite incorporar El Salvador al sistema internacional de
planificación 5G de ChronoOS sin confundir una configuración de software
con un derecho de uso del espectro.

### ChronoOS

Preparado para infraestructura 5G, Core Box, redes privadas y
despliegues controlados.
