# Brazil Spectrum Reference

ChronoNet engineering profile includes the following 5G-related
spectrum areas:

- 700 MHz
- 2.3 GHz
- 3.3–3.7 GHz
- 3.7–3.8 GHz
- 26 GHz
- 27.5–27.9 GHz where applicable to the regulatory profile

These are engineering/reference categories.

Actual authorization, allocation and use must always be checked
against current ANATEL rules.

Official source:

https://www.gov.br/anatel/
