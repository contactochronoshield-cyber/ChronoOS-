# Brazil 5G Profile

ChronoNet Brazil supports engineering profiles for:

- Public 5G
- Private 5G
- 5G NR
- Core Box
- Open5GS / Free5GS integration
- Network planning
- Infrastructure mapping

The Chrono Shield implementation uses established telecom
components rather than attempting to replace the 3GPP core
architecture.

Potential deployment environments:

- Industry
- Mining
- Agriculture
- Utilities
- Logistics
- Enterprise
