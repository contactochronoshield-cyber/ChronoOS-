# ChronoNet GIS — Fuentes de datos

## Colombia

Fuente principal:

Datos Abiertos Colombia / MinTIC / Postdata / CRC

Dataset:

Infraestructura y cobertura de redes de acceso móvil

Identificador:

pyy9-82ts

Portal:

https://www.datos.gov.co/dataset/Infraestructura-y-cobertura-de-redes-de-acceso-m-v/pyy9-82ts

La información es utilizada por ChronoNet GIS como fuente pública de
inteligencia geoespacial de infraestructura telecom.

ChronoNet no obtiene acceso operacional a las redes de terceros.

Los datos públicos se mantienen separados de:

- infraestructura propia
- mediciones propias
- datos operativos autorizados
- información privada
