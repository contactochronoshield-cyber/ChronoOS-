# Chrono Colombia Infrastructure Intelligence

Colombia is a primary Chrono infrastructure profile.

The GIS architecture is designed to consume official public
information and combine it with Chrono-managed infrastructure.

## External layers

Potential layers include:

- Mobile sites
- Coverage
- 4G
- 5G
- Fiber
- Municipal boundaries
- Infrastructure deployment information

The CRC/Postdata platform provides public georeferenced information
about mobile infrastructure and fiber infrastructure in Colombia.

## Chrono layers

Separate layers represent:

- Chrono Sentinel
- Chrono Node
- Chrono Gateway
- Chrono Core Box
- LoRa gateways
- Edge infrastructure
- Verified telemetry

## Important

External infrastructure is reference data.

It is not considered Chrono-owned or Chrono-controlled unless there
is an explicit authorized integration.
