# Chrono Brazil Infrastructure Intelligence

Brazil is a primary Chrono telecommunications profile.

## External layers

Potential layers include:

- Licensed stations
- Mobile coverage
- Municipal coverage
- Technologies
- Spectrum references
- Private network references

ANATEL provides public telecommunications datasets and panels
including licensed mobile radio base stations and mobile coverage.

## Chrono layers

- Chrono Sentinel
- Chrono Node
- Chrono Gateway
- Chrono Core Box
- Edge infrastructure
- Private-network assets
- Verified telemetry

## Important

ANATEL data is external regulatory/reference information.

Chrono does not interpret the presence of a licensed station as
ownership or control by Chrono.
