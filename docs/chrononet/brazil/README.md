# ChronoNet Brazil

Brazil is the flagship international ChronoNet telecom profile.

It combines:

- ANATEL
- Spectrum
- 5G
- Private Networks
- Licensed Infrastructure
- Coverage
- GIS
- Media/IPTV
- Chrono Shield infrastructure
- Engineering audit

The profile is designed as the reference architecture for later
country profiles:

- Colombia
- Peru
- Chile
- El Salvador
- Estonia
