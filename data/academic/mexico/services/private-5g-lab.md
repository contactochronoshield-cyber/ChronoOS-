# ChronoOS Private 5G Academic Lab — Mexico

Laboratorio para investigación universitaria de redes móviles
privadas.

## Arquitectura

- Open5GS
- Private 5G/LTE core
- Laboratory UEs
- SIM/eSIM laboratory profiles
- Network slicing research
- IoT connectivity
- Telemetry
- Security monitoring

El laboratorio no implica autorización para operar espectro
radioeléctrico. Cualquier transmisión deberá cumplir la regulación
mexicana aplicable y utilizar bandas/entornos autorizados.
