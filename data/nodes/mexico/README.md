# ChronoOS — Mexico Nodes

Mexico node registry.

## Privacy

This registry MUST NOT store:

- residential addresses
- precise GPS coordinates
- Wi-Fi SSIDs
- Wi-Fi BSSIDs
- historical public IP addresses
- private IP addresses
- personal names
- phone numbers
- credentials
- private keys

Nodes use coarse geographic information such as city/region.

## Node activation

A node remains `pending` until its operator explicitly provides
consent for participation.

No device is automatically enrolled based on network discovery,
historical connectivity, GPS data or IP addresses.

## Node IDs
