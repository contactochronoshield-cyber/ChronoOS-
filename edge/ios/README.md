# Chrono Mobile — iOS

iOS is integrated through a Chrono Mobile application/SDK.

ChronoOS does not attempt to replace iOS or bypass its security
model.

Supported architecture:

iPhone/iPad
    ↓
Chrono Mobile
    ↓
Chrono Identity
    ↓
ChronoNet

BLE, local-network and background capabilities depend on Apple's
platform permissions and lifecycle rules.
