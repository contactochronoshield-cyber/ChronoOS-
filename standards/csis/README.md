# CSIS — Chrono Sovereign Infrastructure Standard

CSIS is a technical specification developed by Chrono Shield
Systems for interoperable sovereign infrastructure.

CSIS is not a government law and does not replace national
regulations.

CSIS-002 Infrastructure Identity

CSIS-005 Infrastructure Ledger
CSIS-006 Offline Operation
CSIS-007 IoT / LoRaWAN Integration
CSIS-008 Mobile Nodes
CSIS-009 Digital Twin
CSIS-010 Security
CSIS-011 Incident Response
CSIS-012 Infrastructure Lifecycle
CSIS-013 Regional Interoperability
CSIS-014 Data Provenance
CSIS-015 Decommission & Destruction

National regulations always take precedence.
