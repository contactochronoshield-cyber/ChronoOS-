# ChronoOS - Cybernetic Terminal Environment

ChronoOS es un entorno CLI enfocado en soberanía digital, diagnóstico de red, seguridad criptográfica y simulación de un sistema operativo cibernético sobre infraestructura Linux/Termux.

Developed by Chrono Shield Networks.

## Características
- CLI Unificado (chrono): Herramienta de gestión centralizada.
- Integridad Criptográfica: Verificación de firma SHA-256.
- Chrono Vault: Cifrado y descifrado de archivos locales con AES-256 (OpenSSL).
- Gestor PKG: Gestor de paquetes modular de la empresa.
- Auditoría Mesh/Net: Diagnóstico de red local e interfaces.

## Instalación

1. Clona este repositorio:
git clone [https://github.com/contactochronoshield-cyber/chrono-os.git](https://github.com/contactochronoshield-cyber/chrono-os.git)
cd chrono-os

2. Ejecuta el instalador:
bash install.sh

3. Abre el menú interactivo:
chrono
