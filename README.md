## 🚀 Quick Start (Installation & Deployment)

Clona el repositorio e inicializa el entorno de comandos soberanos:

```bash
# Clonar el repositorio oficial
git clone [https://github.com/tu-usuario/chrono-os.git](https://github.com/tu-usuario/chrono-os.git)
cd chrono-os

# Otorgar permisos de ejecución al kernel CLI
chmod +x chrono

# Iniciar la interfaz principal de ChronoOS
./chrono
