# ChronoOS - Kernel & Core Architecture

ChronoOS es un sistema operativo soberano y resiliente diseñado para entornos industriales, tácticos y *air-gapped*, optimizado para cumplir con los estándares de seguridad industrial **IEC 62443**.

## 🛠️ Prerrequisitos de Compilación
* Sistema operativo basado en Linux (Kernel 5.x o superior).
* Compilador GCC con soporte para C99.
* Librería de desarrollo OpenSSL (`libssl-dev`).
