# ChronoOS 1.2.0 — Sovereign Edge

ChronoOS 1.2.0 expands the platform from dedicated infrastructure
to heterogeneous sovereign edge infrastructure.

## Core capabilities

- Hardware identity
- Device identity
- Attestation
- Infrastructure lifecycle
- Ledger integration
- Federation
- Edge nodes
- Fleet management

## Connectivity

- 5G
- 4G
- Wi-Fi
- Bluetooth/BLE
- LoRa
- LoRaWAN

## Edge platforms

- Linux
- Termux
- Android
- iOS
- ESP32
- micro:bit
- Sensor gateways

## Infrastructure

- ChronoNet
- GIS
- Digital Twin
- Sentinel telemetry
- Network anomaly analysis
- Regional compliance profiles

- Brazil
